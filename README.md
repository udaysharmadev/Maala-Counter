# 🙏 Maala Counter

> A dedicated digital prayer counter (mala/tasbih counter) built as a **Native Android App** — designed for Dadi.

[![Build Android APK](https://github.com/udaysharmadev/Maala-Counter/actions/workflows/android-build.yml/badge.svg)](https://github.com/udaysharmadev/Maala-Counter/actions/workflows/android-build.yml)

## The One Rule

**Volume Up button = +1 count. That's it.**

No on-screen tap buttons. No swipes. No keyboard shortcuts. Just the physical Volume Up button on the side of the phone — the same button Dadi already knows how to press.

---

## Why a Native App and Not Just a Website?

This was the core engineering challenge. A regular website running in Chrome **cannot** detect physical volume button presses — Android blocks this at the OS level for security and UX reasons.

| Approach | Volume Up Detection | Works? |
|---|---|---|
| Regular Website (Chrome) | Blocked by browser/OS | ❌ |
| PWA (Progressive Web App) | Still blocked | ❌ |
| Audio Hack (fake volume monitor) | Partially, hits 0%/100% wall | ❌ (unreliable) |
| **Native Android App (Capacitor)** | **Direct hardware access** | **✅ Always works** |

The solution: wrap the web UI inside a **Capacitor native shell**, which gives us full access to Android hardware APIs via native plugins.

---

## Features

- 🔘 **Volume Up only** — single, reliable counting mechanism
- 📳 Haptic feedback on every press
- 🎉 Auto-celebration at 108 counts (traditional maala count)
- 🔄 Auto-reset after 108
- 💾 Persists today's count and all-time total across app restarts
- 🌙 Beautiful dark UI, large readable numbers — easy for elderly users

## How the Build Pipeline Works

This project uses **GitHub Actions** as a free cloud build server. You do **not** need Android Studio or the Android SDK installed locally.

### Pipeline Steps (`android-build.yml`)

```yaml
pipeline_steps:
  step_1: checkout_source_code
  step_2: setup_node_22
  step_3: setup_java_21_temurin       # Capacitor 8 requires Java 21+
  step_4: setup_android_sdk_base
  step_5: install_sdk_platform_36     # sdkmanager "platforms;android-36" "build-tools;36.0.0"
  step_6: write_local_properties      # echo "sdk.dir=$ANDROID_SDK_ROOT" > android/local.properties
  step_7: npm_ci                      # installs JS dependencies from package-lock.json
  step_8: cap_sync_android            # copies src/* into android/app/src/main/assets/public/
                                      # + links native plugins to Android project
  step_9: gradle_assembleDebug        # compiles Java + web assets → app-debug.apk
  step_10: upload_artifact            # makes APK downloadable from GitHub Actions UI
```

### The Two Key Commands

**`npx cap sync android`**
Copies your web files (`src/`) into the Android native project and wires up native plugin bridges. This is what connects your JavaScript code to the Android hardware layer.

**`./gradlew assembleDebug`**
Android's official build engine. Compiles the Java layer, packages the web assets, links all SDK libraries, and outputs a single installable `.apk` file.

## Download the APK

Every push to `main` automatically builds a fresh APK.

1. Go to the [**Actions tab**](https://github.com/udaysharmadev/Maala-Counter/actions)
2. Click the latest successful run ✅
3. Scroll to **Artifacts** → download **`Maala-Counter-APK`**
4. Extract the `.zip` → get `app-debug.apk`

---

## Install on Android Phone

1. Send `app-debug.apk` to Dadi's phone via WhatsApp / USB / Google Drive
2. Tap the file on her phone
3. If prompted: **Settings → Allow from this source** → Install
4. Open **Maala Counter** → press Volume Up → 🙏

## Security — What is NOT in this Repository

| Excluded | Why |
|---|---|
| `node_modules/` | Regenerated by `npm ci` during build |
| `android/local.properties` | Contains local machine SDK path — different on every machine |
| `android/.gradle/` | Gradle build cache |
| `android/app/build/` | Compiled output files |
| `android/app/src/main/assets/public/` | Generated by `cap sync`, not source |
| `*.apk` / `*.aab` | Build artifacts, downloaded from GitHub Actions |
| `*.keystore` | Signing keys — never commit these |

No API keys, tokens, credentials, or personal data are stored in this repository.

## Local Development (Optional)

If you want to run or modify this locally:

**Prerequisites:** Node.js 22+, Java 21, Android Studio (for local builds only)

```bash
# Install dependencies
npm install

# Sync web assets to Android project
npx cap sync android

# Open in Android Studio (optional)
npx cap open android

# Or build APK directly (requires local Android SDK)
cd android && ./gradlew assembleDebug
```
